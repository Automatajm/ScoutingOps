## 📋 CHECKLIST DE VALIDACIÓN PRE-CLIENTE

### **1. VERIFICACIÓN DE SERVICIOS BASE**
```bash
# Validar que todos los contenedores estén operativos
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
```
**✓ Resultado esperado:** 4 servicios activos (backend, frontend, db, pgadmin)  
**⚠️ Acción si falla:** Reiniciar contenedores con `docker-compose up -d`

### **2. CONECTIVIDAD DE PUERTOS**
```bash
# Verificar acceso a puertos críticos
Test-NetConnection localhost -Port 8080
Test-NetConnection localhost -Port 8000
Test-NetConnection localhost -Port 5432
```
**✓ Resultado esperado:** TcpTestSucceeded: True en todos  
**⚠️ Acción si falla:** Verificar firewall o conflictos de puerto

### **3. VALIDACIÓN HTTPS**
```bash
# Confirmar que SSL está operativo
docker exec pest_control_backend curl -k -I https://localhost:8000
docker exec pest_control_frontend curl -k -I https://localhost:8080
```
**✓ Resultado esperado:** HTTP/1.1 200 OK en ambos  
**⚠️ Acción si falla:** Revisar certificados en /backend/certs/

### **4. AUDITORÍA DE DEPENDENCIAS**
```bash
# Ejecutar desde directorio backend
cd C:\Users\owner\desktop\pestcontrol\backend
npm audit
```
**✓ Resultado esperado:** "found 0 vulnerabilities"  
**⚠️ Acción si falla:** Documentar vulnerabilidades y plan de actualización

### **5. ANÁLISIS DE CONFIGURACIÓN**
```bash
# Revisar variables críticas de seguridad
Get-Content .\.env | Select-String -Pattern "SSL|SECRET|CORS"
```
**✓ Validar que contenga:**
- SSL_ENABLED=true
- JWT_SECRET configurado
- CORS_ORIGIN definido

### **6. VERIFICACIÓN DE BASE DE DATOS**
```bash
# Confirmar conexión y estructura
docker exec -it pest_control_db psql -U pestuser -d pest_control -c "\dt"
```
**✓ Resultado esperado:** Lista de tablas del sistema  
**⚠️ Acción si falla:** Verificar credenciales en docker-compose.yml

### **7. HEADERS DE SEGURIDAD**
```bash
# Analizar headers HTTP de respuesta
docker exec pest_control_backend curl -k -I https://localhost:8000 | grep -E "Access-Control|Content-Type|X-"
```
**✓ Validar presencia de:**
- Access-Control-Allow-Origin
- Content-Type
- X-Powered-By (controlado)

### **8. LOGS DE APLICACIÓN**
```bash
# Revisar logs recientes para errores
docker logs pest_control_backend --tail 50
docker logs pest_control_frontend --tail 50
```
**✓ Resultado esperado:** Sin errores críticos  
**⚠️ Acción si hay errores:** Documentar y corregir antes de presentación
